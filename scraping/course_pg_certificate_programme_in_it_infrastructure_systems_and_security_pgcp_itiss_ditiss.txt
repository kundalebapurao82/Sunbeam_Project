Syllabus
What You'll Learn
The theoretical and practical mix of the Post Graduate Certificate Programme in IT Infrastructure, Systems and Security (PGCP-ITISS) programme has the following focus: Understanding the concepts of data center management, application security implementation and using various techniques for ethical hacking and cyber forensics Analyzing threat detection techniques, intrusion detection and prevention measures Use advanced tools/decision making instruments/techniques to analyse complex problems and be prepared to develop such new techniques for the future Learning cloud computing, accessing the resources and services needed to function with dynamically changing needs, thereby applying cloud privacy and security concepts to cloud platforms to create a secure cloud environment To analyze and solve conceptual and practical problems from diverse industries such as government manufacturing, retail, education, banking/finance, healthcare, and pharmaceutical Undertake industrial research projects to develop future solutions in the field of information security to impact technological advancement After completing this course, students can work as: System administrator Network Security Professional Web Security Checker Information Security Analyst
Course Description
The objective of this course is to enable students to understand the concepts of network security and learn techniques to detect attacks and secure the network from internal and external attacks. At the end of the course, students will be able to recognize various common security threats and vulnerabilities, understand the principles and practices of cryptographic techniques, identify and analyze security problems specific to a given application, and apply appropriate security techniques to address security issues.
