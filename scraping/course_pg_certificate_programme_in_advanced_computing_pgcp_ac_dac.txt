Overview
Syllabus
What You'll Learn
After completing the course students will be able to acquire the following skills:
Using technologies to effectively access and interpret information
Apply their analytical skills to investigate unfamiliar problems using web technologies like HTML 5.0, CSS, Java Script, Jquery, React JS
Using quantitative data confidently and competently
Using communication technologies effectively
Understanding the multi-tier architecture of the web-based enterprise applications used. Enterprise JavaBeans. Integrating Servlets, JSPs with EJBs and databases in a J2EE application
NET architecture, developing and maintaining applications
Course Description
This course is targeted towards engineering graduates and MCA/MSc who wish to enter the field of advanced computing. The aim of this course is to prepare students to be able to work in the current technological landscape, keep pace with the changes taking place in technology and meet the needs of the ever-growing information technology industry. The entire curriculum, syllabus, teaching methodology and course style are based on the rich research and development background of C-DAC. The PGCP-AC course, running successfully for over 25 years, has produced thousands of professionals who are well placed in the industry today.
